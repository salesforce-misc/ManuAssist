# Manufacturing / Automotive Cloud Personas

Distilled from `manufacturing_admin.pdf` (the Permission Set Licenses table, Set Up Manufacturing Cloud chapter, and per-feature overviews). Use this catalog to resolve the **right persona** for any UJ — never default to "Admin" or "Sales Manager".

The `Verbs` column is what to write in the UJ's User Action column for that persona — it keeps the journey persona-correct.

## Persona Resolution Rules

1. **Setup persona is almost always System Administrator + a feature-specific admin** (Sales Ops Manager for targets/agreements, DPE Admin for forecasts/programs, Warranty Admin for warranties).
2. **Transactional persona = the persona named in the feature's "Who Needs The License" column** of the PSL table in the admin PDF. Look that up before writing the journey.
3. **Two-persona transactional flows** (Sales Manager schedules a visit → Field Rep executes) MUST be authored as two consecutive scenarios with distinct personas in the User Action column — not collapsed into "the user".
4. **External / Experience Cloud persona** is required whenever the feature has a `For Community Psl` variant (Sales Agreements, Advanced Account Forecasting, Partner Visit Management, Rebates, Warranty Claims).
